# McDonald's Equity Research Case

Independent equity research case on McDonald's Corporation (NYSE: MCD), prepared as a student project for educational purposes.

## Project Overview

This project analyses McDonald's Corporation through a fundamental equity research framework, including business model analysis, investment thesis, financial forecasting, DCF valuation, peer multiples, sensitivity analysis, scenario analysis, risks and catalysts.

## Key Outputs

- 6-page equity research report
- DCF valuation
- Peer multiple valuation
- WACC and beta analysis
- Bear/base/bull scenario analysis
- Sensitivity analysis
- Risks and catalyst calendar

## Files

- [Equity Research Report PDF](report/William_Challma_McDonalds_Equity_Research_Report.pdf)
- [Presentation File](presentation/MCD_Equity_Research_Report_Final.pptx)

## Methodology

The valuation combines a discounted cash flow model and peer multiple analysis. The investment thesis focuses on McDonald's franchise economics, traffic trends, refranchising, margin expansion, shareholder returns and interest rate sensitivity.
